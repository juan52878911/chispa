# Código de conducta

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
como código de conducta. En resumen:

- Trata a los demás con respeto, en issues, PRs, revisiones y cualquier otro espacio del proyecto.
- Critica ideas y código, no personas. Nada de acoso, insultos, ataques personales ni lenguaje o imágenes sexualizadas.
- No publiques datos privados de nadie sin su permiso.
- Quien mantiene el proyecto puede editar o borrar comentarios, commits o issues que no cumplan estas normas, y bloquear a quien
  las incumpla de forma repetida.

Para informar de un comportamiento inaceptable, escribe de forma privada a quien mantiene el proyecto (perfil de GitHub del
propietario del repositorio). Todas las quejas se revisan y se tratan con confidencialidad.

---

This project adopts the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Be respectful,
