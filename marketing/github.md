## Descripción (máx. 350 caracteres)

**ES** (elegida por defecto, el README principal está en español):

> Servidor de clasificación tipada de código abierto: texto + pregunta cerrada (choice, sí/no, score) → opción, probabilidad por opción y aviso de «no seguro». Modo clásico entrenado por tarea (CPU y móvil), modo CPU con kNN sobre tus ejemplos y modo GPU con Qwen3-4B. Go, Apache-2.0.

**EN** (alternativa):

> Open-source typed classification server: text + closed question (choice, yes/no, score) → option, per-option probability and a "not sure" flag. Classic per-task trained mode (CPU and mobile), CPU mode with kNN over your examples, GPU mode with Qwen3-4B. Go, Apache-2.0.
